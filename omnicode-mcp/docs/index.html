Connect it to your agent

OmniCode is a stdio MCP server, so it plugs into Claude Desktop, Claude Code, Cursor, Codex, Cline, and any MCP client.

Claude Code (one command)

$ node /path/to/omnicode-mcp/dist/cli.js mcp-config --client claude-code

First call every agent should make

// Returns: branch, last commit, 30-day churn, top contributors,
// stack (manifests, frameworks, primary language), top 10 symbols
// by importance, indexed state, health, blindspots, exact next action.
invoke_tool({ tool_name: "session_resume_brief", tool_input: { path: "E:/path/to/repo" } })

Why OmniCode

◉

Honest coverage

Every discovered file ends in one of 8 proven resolution states. No silent skips, no fake "100%". If a guard trips, the index says so.

◐

Hidden-by-default surface

8 public tools in the LLM's context. 33 more live behind invoke_tool with RBAC. No tool-schema bloat. No agent-side config tax.

◑

Audit trail you can trust

Every call records its caller, repo, and a stable SHA-256 of its arguments. Diff the audit table by payload signature to spot anomalous agent behavior.

◒

Real PageRank, not edge count

Symbols are ranked by an actual PageRank pass over the import graph. Importance queries mean something. get_top_symbols returns the symbols that matter.

▲

Sandbox + repair governor

Path traversal blocked, secrets redacted, destructive edits refused on partial index or unknown repos. The repair governor is opinionated on purpose.

▶

One binary, every client

Claude Desktop, Claude Code, Cursor, Codex, Cline, Windsurf, Copilot. omnicode mcp-config --client <name> prints the config block.
